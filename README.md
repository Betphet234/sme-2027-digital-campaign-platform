# SME for Esan Central 2027 - Website Starter

This folder contains a mobile-first static website prototype based on the supplied campaign brief.

## What is included

- 20 requested website pages, plus a thank-you/acknowledgement page
- Blue, red and white campaign design
- Opportunity application portal with forms for:
  - Job seekers
  - Business startup applicants
  - Existing businesses seeking expansion
  - Newly freed apprentices
- Community Needs Portal
- Volunteer, join campaign, contact and donor pledge forms
- Application reference number generation
- Application status checker and printable acknowledgement slip
- Admin dashboard prototype with filters, internal notes, status changes, duplicate phone detection and CSV export
- News/media layout with sharing links
- Event calendar placeholder
- Newsletter subscription demo
- WhatsApp button
- Downloadable manifesto preview PDF

## Important production note

This is a front-end/static prototype. It stores test submissions in the visitor's browser localStorage only. For a real campaign website, connect it to a secure backend, database and hosting environment with:

- SSL/HTTPS
- Server-side form handling
- Secure file uploads
- Authentication and role-based access
- Two-factor authentication for administrators
- CAPTCHA/spam protection
- Encrypted backups
- Audit logs
- Email/SMS notifications
- Privacy policy and legal review

## How to preview

Open `index.html` in a browser, or upload the full folder to a web host/static hosting service.
### Admin Access

Administrative access is not included in this public repository.

For security reasons, production credentials and authentication secrets are excluded from source control.
